FATAL FLAW
  • 숙제 자가 채점의 오류: 동일한 LLM에게 "코드 리뷰 및 테스트 작성"을 맡기면 본인이 빠뜨린 논리 결함을 그대로 간과함. Grading Own Homework: When the same LLM reviews code, it shares identical inductive blind spots and produces false approvals.
  • 초록불(Green Test)의 환상: "테스트가 모두 통과했으니 안전하다"고 믿지만, 실제로는 아무런 결함도 공격하지 못하는 무의미한 assertion일 뿐임. Illusion of Green Tests: Passing test suites often assert superficial paths without stressing real concurrent boundaries.

MATHEMATICAL GUARANTEE

테스트가 원본 PR에서 실패하거나 문법 오류로 깨진 경우는 변이체 탐지 점수에서 완전히 배제됩니다. 오직 원본 PR 코드는 무결하게 통과(Pass)하면서 변이 코드에서는 정확히 실패(Fail)를 유발한 테스트만이 유효 처치(Killed)로 인정됩니다: Tests failing on original code or breaking on syntax are strictly excluded. A mutant $M_i$ is caught ONLY IF the test passes on original PR but fails on $M_i$:

Caught(M_i) ⇔ ∃ t_j ∈ T : Pass(t_j, PR_orig) ∧ Fail(t_j, M_i)
