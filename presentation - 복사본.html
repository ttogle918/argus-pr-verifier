MATHEMATICAL GUARANTEE

테스트가 원본 PR에서 실패하거나 문법 오류로 깨진 경우는 변이체 탐지 점수에서 완전히 배제됩니다. 오직 원본 PR 코드는 무결하게 통과(Pass)하면서 변이 코드에서는 정확히 실패(Fail)를 유발한 테스트만이 유효 처치(Killed)로 인정됩니다: Tests failing on original code or breaking on syntax are strictly excluded. A mutant $M_i$ is caught ONLY IF the test passes on original PR but fails on $M_i$:

Caught(M_i) ⇔ ∃ t_j ∈ T : Pass(t_j, PR_orig) ∧ Fail(t_j, M_i)

REPRODUCIBILITY

AI가 생성한 동시성 및 네트워크 테스트는 일시적인 타이밍 차이로 1회만 실패하고 사라지는 'Flaky 테스트'가 빈번합니다. Argus-PR은 원본 코드에서 실패한 테스트를 반드시 연속 2회 재실행(2x Repro)하여 2/2 모두 동일하게 실패한 진짜 버그만 사용자에게 보고합니다. AI-generated concurrent tests often produce flaky, intermittent failures. Argus-PR enforces a strict 2-run reproduction check: only tests failing consecutively in 2 of 2 executions are classified as confirmed PR defects.

AI agents ruthlessly discover defects and objectively prove verification visibility (7/8 Blind Score). The ultimate authority to merge, accept self-healing patches, or reject code rests entirely in the hands of the human engineer via the One-Card Decision Gate.
