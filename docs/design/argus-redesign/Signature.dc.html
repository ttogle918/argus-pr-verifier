Final frame · deterministic_scoring

Seven eyes open. One stays shut.

The core is the PR. The eight lids on its surface are the planted mutants. Each one a test catches opens and glows green. M8 was never caught, so it stays closed and turns yellow: the miss is the part a reviewer should notice.

It is drawn in 2D (SVG) by default; a 3D renderer is optional and takes the same state. It lives on Start in its idle state and docks above the lanes on Run. Every movement is triggered by an event from /api/verify/stream. Nothing loops on its own.

Keyframes, driven by the event stream

  1. 1 · invariants_extracted Eight closed lids fade in. The attackers take their orbits.
  2. 2 · sandbox_track_a One beam per test result. Orange = breached the PR, yellow = flaky, gray = held.
  3. 3 · sandbox_track_b A green beam reaches a lid and it opens. Here M6 is mid-open, with 5 of 8 already open.
  4. 4 · deterministic_scoring Beams clear and attackers stop. The uncaught lid turns yellow and stays shut.
  5. alt · blocked The guardrail stops the PR at Stage 0: no attackers, no lids, and an orange outline on the core.

Motion spec

Every motion is about 300 ms and plays once per event. With prefers-reduced-motion, each change snaps to its end state.

Optional 3D renderer · same state, same events

3D is an upgrade, not a dependency.

If time allows, a Three.js renderer can draw the same state object as a translucent core with lids on its surface and attackers on tilted orbits. It adds depth, not information, so the 2D ring stays the default and the 3D view drops back to it:

  • Switch when WebGL is unavailable, or the median frame time is over 33 ms (under ~30 fps) across the first 60 frames of a run.
  • prefers-reduced-motion shows the 2D version with state changes snapped, no tweening.
  • The swap crossfades over 300 ms (instant with reduced motion) and never switches back during a run.
  • Pause rendering when the tab is hidden. Cap the pixel ratio at 2.
